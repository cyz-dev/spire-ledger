# 实际战损页没有遭遇图

状态：已解决（2026-11-01，维护者接手 PR #20）。相关规格：[product.md](../product.md)「实际战损」、[architecture.md](../architecture.md) `EncounterArt`、[testing.md](../testing.md) W16。

## 现象

0.6.0-beta.1 去掉打包的遭遇图以后，“战斗与资源 → 实际战损”和它的导出图里，每个遭遇只剩一张空白卡框。PR #20 的第一版改成只读玩家自备的图片目录，第一次打开时建一个空文件夹和 `README.txt`；没有放图的玩家看到的仍然全是空白。

## 决定

遭遇图用玩家本机游戏的怪物资源在运行时绘制：生成游戏为该遭遇创建的怪物，按待机姿态离屏画出并裁剪。玩家放在 `~/.spire-ledger/monster-images/` 或 `mods/SpireLedger/monster-images/` 里的同名图片优先，作为换图。发布包仍然不带任何图片，`build.ps1` 的图片闸门保留。

PR #20 曾否掉“运行时从游戏资源画”，理由是“依赖内部图集布局，版本一变就碎”。本 Mod 只支持游戏 `12-18-2022` 一个版本，这个理由不成立；画法直接复用游戏自己的怪物类和渲染器，不解析图集布局。生成怪物会消耗地牢随机数，绘制期间用临时随机数替换、结束后放回。

## 没有采纳的选项

| 选项 | 不采纳的理由 |
|---|---|
| 把遭遇图打进 jar | 公开仓库分发游戏美术 |
| 首次运行时联网下载图包 | 仍是分发美术；离线不可用 |
| 读 TinyCat 的图片目录 | 把功能绑在另一个 Mod 的安装状态上 |
| 只读玩家自备图片（PR #20 第一版） | 绝大多数玩家没有图，页面仍是空白 |

## 验收

- `StatsOptionsProbe`：实际战损导出时 90% 以上的遭遇由游戏资源画出（2026-11-01 实测 20/20）；生成小鬼群前后 `monsterHpRng`、`miscRng` 计数不变；未知遭遇不画道歉史莱姆。
- W16 手测。
