Last updated: 2026-10-30（`v0.5.0`）
Product spec: [product.md](product.md) · Metrics: [metrics.md](metrics.md)

维护者已做过离线断言（`build.ps1 -Check`）和隔离实例里的原生探针。beta.2 发布前已在 SuperFastMode 1.0.8、10 倍速下，通过真实 HistoryScreen 的回合下拉和重打按钮验证当前战斗回退，并核对状态、随机数状态及相同行动的结果。原生 UI 选牌仍记录为 human。Windows 上的独立练习也已通过：子进程保留 10 倍速，恢复状态与相同行动结果一致，源记录未改变。探针由程序驱动，下面的快速清单主要检查实际游玩体验。

新版复盘用真实记录副本检查 1024×768 和 1920×1080 的悬停、固定、牌组和返回操作，并核对源 JSON 和 13 个游戏 RNG 不变。8 Mod 组合下已验证回合录制、原生重打按钮、求解器旧结果清空和相同行动结果。

结果不符合预期时，记下职业、楼层并截图，按 Ctrl+Shift+R 生成错误报告，位置是 `~/.spire-ledger/bug-reports/`。测试结果可以直接开 issue，格式参考[已关闭问题](https://github.com/cyz-dev/spire-ledger/issues?q=is%3Aissue+state%3Aclosed)：版本、Mod 列表、复现步骤、期望与实际、截图。

已知边界，按预期记录即可，不算失败：

- 标准率没有置信区间：1000 次自助法会跑在渲染线程上，TinyCat 的区间没有移植；一般率仍显示分子/分母。
- 标准率是个人选择行为的描述，不是卡牌强度，也不是和一般率相减的“净收益”。
- 涅奥标准率只覆盖有未选记录的局（原版 `neow_bonuses_skipped_log`/`neow_costs_skipped_log`，或账本 `NEOW_OPTION` 的候选）；旧局缺失属预期。
- 火堆候选池由 `.run` 逐层重放牌组恢复；改卡 Mod、未覆盖的遗物或异常移除可能让重建覆盖率下降，界面会显示重建覆盖，样本不足的条目单列。
- 长图可能很高（本机火堆标准率约 16500px），部分图片查看器会缩放；以文件本身为准。

## C. 可选（有兴趣再测）

维护者决定不把这两项作为发布前的验收项（2026-10-25）。有兴趣的测试者欢迎测一下，并把结果贴在 issue 里。

**C1 金币估算误差。** 统计里的“累计获得金币”有两种来源。用本 Mod 录的局，记的是游戏内的精确值；只有原版 `.run` 的旧局，是按 TinyCat 的公式估算的。用新版本打至少 10 局后运行：

```powershell
java -cp "build\gson;build\stats-classes" spireledger.stats.GoldCheck <游戏目录>\runs $env:USERPROFILE\.spire-ledger\runs
```

它会逐局打印精确值、估算值和差值，最后给出平均绝对误差和最大误差。TinyCat 在它作者的数据上报告的是 38 和 160。

**C2 千局性能。** 维护者在 1000 局合成记录上实测过：打开统计约 6 秒，每次决策的主线程停顿 p95 约 10 毫秒（[decisions/2026-10-25-review.md](decisions/2026-10-25-review.md)“M1 性能实测”）。这是新统计内核之前的数字。复测方法如下：

1. 用 `java -cp ... spireledger.SummaryPerf make <你的 ~/.spire-ledger/runs> <空目录> 1000` 生成 1000 局。
2. 把生成目录当作一个隔离游戏实例的 `~/.spire-ledger/runs`。
3. 记录从点开统计页到数字显示出来的时间。

**C3 用自己的数据和 TinyCat 对数。** 方法见 [tools/tinycat-compare/README.md](../tools/tinycat-compare/README.md)。维护者的数据已经对到 0 处未归类差异。不同玩家的数据可能暴露新的差异；如果出现未归类差异，把 `compare.py` 的报告贴上来。

## 暂时不能测

- 与求解器 Mod 同装时，求解器动作自动标为“已知自动化”。这需要求解器一侧先接入，计划在 M3。
- 遗物效果量（读 Relic Stats 的数据）、其他 Tierlist 和可配置分档阈值，计划在后续版本。
- 标准化率的置信区间与自然断点参数复测：当前只移植 TinyCat 的点估计和 Jenks 分档，没有移植自助法区间；份额为描述性结果，不作为强度结论验收。

标准化抓率、涅奥/Boss 标准率、涅奥/Boss 选后胜率、火堆标准化倍和 `metrics.csv` 导出已经可以测试，见上文 W1–W6 与 N2–N5；卡牌实际抓率 PNG 仍可回归。
