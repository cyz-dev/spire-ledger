# Spire Ledger（尖塔账本）

《杀戮尖塔 1》本地记录、统计与复盘 Mod：如实记录每局的选择与资源，汇总成玩家自己的统计和 Tierlist，支持按层复盘与回合重打。离线运行，不上传。

- 产品定义：[docs/product.md](docs/product.md)
- 结构与路线：[docs/architecture.md](docs/architecture.md)

当前状态（2026-10-25）：M0、M1 完成，M2 统计内核已合入，与 TinyCat 逐表对数通过。GitHub 内测中，待测试内容见 [docs/testing.md](docs/testing.md)。
